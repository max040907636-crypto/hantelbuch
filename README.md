# Hantelbuch

Mein Gym-Plan als Web-App: 3er-Split (Mi Arme & Schultern, Fr Brust & Rücken, Sa Beine & Bauch),
Trainings-Tagebuch mit Level-Anzeige, Pausen-Timer, Check-Liste im Kalender und täglicher Dehnplan.

- Öffnen: https://max040907636-crypto.github.io/hantelbuch/
- Aufs Handy: Link öffnen → „Zum Home-Bildschirm“
- Daten bleiben im Browser auf dem Gerät (Sicherung unter „Mehr“).
- Videos: eigene Animationen (HyperFrames). Level-Richtwerte: strengthlevel.com.
